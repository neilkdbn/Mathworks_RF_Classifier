# Phase 1 & 2: RF Dataset Processing Pipeline
**Owner:** Arya (Signal Processing Lead)

This repository contains Arya's signal processing layers for inspecting, loading, validating, and preprocessing the MathWorks RF Signal Classification dataset generated by Neil.

## Scope of Phase 1: Inspection & Loading
- **Dataset Loader:** Standardize the loading of MATLAB `.mat` dataset to present a uniform data structure.
- **Input Validation:** Enforce data contracts natively, ensuring the signal representation, labels, and missing metadata (e.g. Fs and SNR) are verified.
- **Data Contract:** Defined in `docs/DATA_CONTRACT.md`. Note: `Fs` (1 MHz) and `SNR` (10 dB) are derived from the generator configuration, as they are not saved explicitly per-frame in `rf_dataset_v1.mat`.

## Scope of Phase 2: Signal Preprocessing
- **Objective:** Improve signal consistency across frames and eliminate artifacts without destroying the underlying QPSK/16-QAM modulation characteristics.
- **Processing Stages:**
  1. Input acquisition & quality analysis
  2. DC offset removal (per frame)
  3. Amplitude normalization (RMS scaling per frame)
  4. Optional low-pass filtering (Disabled by default to prevent phase distortion)
- **Design Details:** Refer to `docs/PHASE2_PREPROCESSING.md` for justification on normalization methods and filtering constraints.

## Created Architecture
- `preprocessing/load_rf_dataset.m` (Load structure)
- `preprocessing/validate_input.m` (Validation)
- `preprocessing/analyze_signal_quality.m` (Compute statistics)
- `preprocessing/remove_dc_offset.m` (Subtract mean I/Q per frame)
- `preprocessing/normalize_amplitude.m` (Scale to unit RMS)
- `preprocessing/apply_filter.m` (Optional zero-phase filtering)
- `preprocessing/preprocess_iq.m` (Main pipeline entry point)
- `visualization/` (Scripts to plot temporal components and constellations)
- `scripts/compare_preprocessing.m` (Compare raw vs processed)

## How to Run the Pipeline
```matlab
% In MATLAB Command Window:
addpath('preprocessing');
data = load_rf_dataset('../rf_dataset_v1.mat');
processedData = preprocess_iq(data);
```

## How to Run Visualizations
```matlab
% Compare Raw vs Processed Signals visually
cd scripts/
run compare_preprocessing.m
```
