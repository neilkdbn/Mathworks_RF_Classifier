# Phase 1: RF Dataset Inspection & Validation
**Owner:** Arya (Signal Processing Lead)

This repository contains the Phase 1 implementation for inspecting, loading, and validating the MathWorks RF Signal Classification dataset generated by Neil.

## Scope of Phase 1
- **Dataset Inspection:** Inspect the variables, datatypes, and dimensions of `rf_dataset_v1.mat`.
- **Dataset Loader:** Standardize the loading of MATLAB `.mat` dataset to present a uniform data structure for preprocessing.
- **Input Validation:** Enforce data contracts natively, ensuring the signal representation, labels, and missing metadata (e.g. Fs and SNR) are explicitly verified.
- **Data Contract:** Define the exact nature of the RF data transitioning from the signal generation phase (Neil) to signal processing (Arya) and later modeling (Shreeya).

## Dataset Inspection Results
Inspection of `rf_dataset_v1.mat` identified:
- `numFrames` (1x1 uint16)
- `samplesPerFrame` (1x1 uint16)
- `qpskData_realistic` (1024x1000 complex double)
- `qamData_realistic` (1024x1000 complex double)
- **Missing Information:** Sample frequency (`Fs`), `SNR` settings, and explicit categorical arrays for `labels` were notably absent from the stored MAT file.

## Data Contract Summary
- **Data type:** Double precision baseband IQ (`complex`)
- **Dimensions:** 1024 samples/frame, 1000 frames/class (2000 frames total).
- **Classes:** 2 classes (QPSK, 16-QAM).
- Missing metadata fields (like Fs) generate MATLAB warnings during validation instead of failing directly, maintaining a resilient interface.

## Created Files
- `scripts/inspect_dataset.m` (Script for displaying variables and properties of the RF dataset)
- `preprocessing/load_rf_dataset.m` (Loads and structures the raw data)
- `preprocessing/validate_input.m` (Validates the structured data against rules)
- `docs/DATA_CONTRACT.md` (Formal description of data interface)
- `tests/test_dataset_loader.m` (Unit tests for dataset loading)
- `tests/test_input_validation.m` (Unit tests for struct validation)
- `README_SIGNAL_PROCESSING.md` (This file)

## How to Run Dataset Inspection
```matlab
% In MATLAB Command Window:
cd scripts/
run inspect_dataset.m
```

## How to Load and Validate the Dataset
```matlab
% In MATLAB Command Window:
addpath('preprocessing');
data = load_rf_dataset('../rf_dataset_v1.mat');
isValid = validate_input(data);
```

## How to Run Tests
```matlab
% In MATLAB Command Window:
addpath('preprocessing');
addpath('tests');
result = runtests('test_dataset_loader.m');
result2 = runtests('test_input_validation.m');
```

## Dependencies
- MATLAB R2021a or newer (recommended for `matlab.unittest.TestCase`)

## Limitations
- Metadata (SNR, Fs) generated by Neil's `generate_signals.m` is not currently saved directly into `rf_dataset_v1.mat`. The loader extracts the classes from variable names and issues warnings for missing metadata.
