# PHASE 3: FEATURE EXTRACTION

This document details the time/frequency features extracted for the Deep Learning framework. 

## Objective
Convert the unified, centered, and RMS-normalized complex baseband signals from Phase 2 into deterministic, structured features suitable for Deep Learning:
1. I/Q sequence representations for 1D-CNN or LSTMs.
2. STFT time-frequency representations for 2D-CNNs.

## Input Contract
Phase 3 functions strictly consume `processedData` struct generated by `preprocess_iq.m` (Phase 2 output).
It does **not** re-normalize, re-filter, or remove DC offsets.

## Representation 1: I/Q Sequences
The complex signal `x[n] = I[n] + jQ[n]` is mapped explicitly to:
`[Samples x 2 x Frames]`
- Dimension 1: Samples (1024)
- Dimension 2: Channels (1=I, 2=Q)
- Dimension 3: Frames (2000 total)

## Representation 2: STFT (Time-Frequency)
A Short-Time Fourier Transform transforms each frame.
### STFT Parameters
- `windowLength`: 64
- `overlapLength`: 48
- `fftLength`: 64
**Scientific Justification:** The original generator produced signals at 1 MHz baseband with an 8 sample-per-symbol pulse shaping filter. A 64-sample window encompasses exactly 8 symbols, balancing time resolution against frequency smearing. A 75% overlap (48 samples) provides smooth time transitions. The 64-point FFT yields 64 frequency bins, making the output structurally comparable to a square image (roughly 64x61) appropriate for standard 2D-CNN architectures.

### STFT Scaling
- The feature is extracted as a **Log Power** representation (`10 * log10(abs(S).^2 + eps)`). 
- It is generated strictly as real values to fulfill 2D-CNN input constraints.

## Frame Alignment
A `frameIds` vector rigorously matches `features.IQ.data(:, :, k)` and `features.STFT.data(:, :, k)` back to `features.labels{k}` and metadata `Fs`, `snr`.

## MATLAB Toolboxes
- `Signal Processing Toolbox` is required for the `stft` function computation.
